Product Requirements Document cho nền tảng tìm kiếm sự kiện, đặt vé, thanh toán, quản lý vé và định hướng frontend React.

01
Overview

Tổng Quan Sản Phẩm

Event Booking App là hệ thống giúp người dùng khám phá sự kiện, xem chi tiết, đặt vé, thanh toán và quản lý vé đã mua. Admin quản trị danh sách sự kiện, còn frontend React đóng vai trò giao diện chính cho người dùng cuối và admin.

Mục tiêu cốt lõi

A

Khám phá sự kiện

Cho phép người dùng xem sự kiện phổ biến, sắp diễn ra, gần vị trí hiện tại và tìm kiếm theo từ khóa.

B

Đặt vé nhanh

Người dùng chọn số lượng vé, tạo booking và nhận tổng tiền rõ ràng trước khi thanh toán.

C

Quản lý vé

Sau thanh toán, người dùng xem lại vé/booking của mình và trạng thái thanh toán.

D

Quản trị sự kiện

Admin có quyền tạo, cập nhật và xóa sự kiện với kiểm soát JWT/role.

REST API

Backend API Target

API target sử dụng response envelope thống nhất gồm `success`, `message`, `data` hoặc `errors`. Tất cả endpoint ngoài auth yêu cầu JWT hợp lệ.

ModuleMethodEndpointQuyềnMục đích
AuthPOST/api/auth/registerPublicTạo tài khoản bằng fullName, email, password.
AuthPOST/api/auth/loginPublicXác thực và trả JWT accessToken.
EventsGET/api/eventsPublic/UserLấy danh sách, search, type, page, size.
EventsGET/api/events/{id}Public/UserXem chi tiết sự kiện.
EventsPOST/PUT/DELETE/api/events, /api/events/{id}ADMINTạo, cập nhật, xóa sự kiện.
BookingPOST/api/bookingsUSERĐặt vé theo eventId và quantity.
TicketsGET/api/ticketsUSERXem vé/booking của người dùng.
PaymentPOST/api/paymentsUSERThanh toán booking chưa paid.
UserPUT/api/users/profileUSERCập nhật fullName và avatar.
UserPUT/api/users/remindersUSERBật/tắt nhắc nhở sự kiện.

Response Envelope

{ "success": true, "message": "Operation successful", "data": {} }
{ "success": false, "message": "Validation failed", "errors": [ { "field": "email", "message": "Invalid email format" } ] }

05
React Frontend

Định Hướng Frontend React

Frontend React là phần đề xuất triển khai tiếp để biến backend API thành trải nghiệm sản phẩm hoàn chỉnh. MVP không cần SSR; Vite là lựa chọn nhẹ, nhanh và phù hợp dự án học tập/MVP.

Stack

  • React + Vite
  • React Router
  • Axios hoặc Fetch wrapper
  • Context API hoặc Zustand
  • Tailwind, CSS Modules hoặc SCSS

Routes

  • / danh sách sự kiện
  • /events/:id chi tiết
  • /login, /register
  • /tickets, /profile
  • /admin/events

API Client

  • Gắn JWT tự động
  • Redirect login khi 401
  • Hiển thị 403 rõ ràng
  • Parse validation `errors`
  • Chuẩn hóa loading/error state

Luồng UI chính

Event Listing→ Event Detail→ Booking→ Payment→ My Tickets

Khu vựcSpec mục tiêuCode hiện tạiHành động đề xuất

SecurityJWT bảo vệ endpoint, 401/403 chuẩn.SecurityConfig lỗi cú pháp; JWT filter/service skeleton.Sửa compile, thêm `@Configuration`, hoàn thiện filter/service.

ServiceAuth/Event/Booking/Payment xử lý nghiệp vụ.Event/Booking/Payment service implementation skeleton.Hoàn thiện nghiệp vụ theo API spec.
EventsCRUD admin, list filter, detail.Controller mới có GET list/detail.Thêm POST/PUT/DELETE và filter query.
Tickets/User`/api/tickets`, profile, reminders.Chưa có TicketController; UserController rỗng.Thêm endpoint, DTO, service.
PaymentRequest body có bookingId/cardNumber/expiry/cvv.PaymentController dùng request param bookingId.Tạo PaymentRequest và response chuẩn.
