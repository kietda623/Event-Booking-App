01
Overview

Tổng Quan Sản Phẩm

Event Booking App là hệ thống giúp người dùng khám phá sự kiện, xem chi tiết, đặt vé, thanh toán và quản lý vé đã mua. Admin quản trị danh sách sự kiện, còn frontend React đóng vai trò giao diện chính cho người dùng cuối và admin.

Mục tiêu cốt lõi

A

Khám phá sự kiện

Cho phép người dùng xem sự kiện phổ biến, sắp diễn ra, gần vị trí hiện tại và tìm kiếm theo từ khóa.

B

Đặt vé nhanh

Người dùng chọn số lượng vé, tạo booking và nhận tổng tiền rõ ràng trước khi thanh toán.

C

Quản lý vé

Sau thanh toán, người dùng xem lại vé/booking của mình và trạng thái thanh toán.

D

Quản trị sự kiện

Admin có quyền tạo, cập nhật và xóa sự kiện với kiểm soát JWT/role.

05
React Frontend

Kiến Trúc Frontend React Đã Scaffold

Frontend React hiện đã được tạo trong repo theo hướng hai app riêng: end-user app và admin web. Cả hai dùng Vite + React + TypeScript + Tailwind + shadcn-style shared UI, proxy `/api` về backend Spring Boot port 8080.

Workspace

  • frontend/apps/user chạy port 5173
  • frontend/apps/admin chạy port 5174
  • frontend/packages/shared chứa API/types/auth/UI
  • NPM workspaces tại frontend/package.json

User Routes

  • /, /events/:id
  • /login, /register
  • /bookings, /bookings/:id/payment
  • /tickets, /favorites, /profile

Admin Routes

  • /login
  • /admin/events
  • /admin/events/new
  • /admin/events/:id/edit
  • Role guard dựa trên GET /api/users/profile

Shared API Contract

Frontend foundation: Shared package tự động gắn JWT từ localStorage, clear session khi 401, parse lỗi backend `{ success:false, message, errors }`, và gom service cho auth, events, bookings, payments, tickets, users và favorites.

Luồng UI chính

Event Listing→ Event Detail→ Booking→ Payment→ My Tickets
Admin Login→ Role Check→ Event Table→ Create/Edit→ Delete

Sequence - Register

sequenceDiagram
  actor Client
  participant AuthController
  participant AuthService
  participant UserRepository
  participant RoleRepository
  participant PasswordEncoder
  participant JwtService

sequenceDiagram

    PaymentService->>BookingRepository: save(Booking PAID)
    PaymentService->>PaymentRepository: save(Payment PAID)

    PaymentService-->>PaymentController: PaymentResponse
  end
